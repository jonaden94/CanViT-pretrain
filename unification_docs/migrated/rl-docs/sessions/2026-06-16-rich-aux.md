# 2026-06-16 (eve) — RICH-AUX policy: matches the anchor at ~1/6 the forwards, beats EG-C2F everywhere

**Headline (single seed, full-val 512² paper protocol):** a viewpoint-Q policy fed a curated set of
scale-equalized auxiliary features reaches the c64 anchor's quality at a *fraction* of the glimpse-forwards
and clearly beats EG-C2F at every horizon. This is the most promising result to date and is being graduated
out of `throwaway/` into the real `q/` pipeline.

> Process failure to own: this trained in `throwaway/rich_aux_train.py` with NO checkpoint saving for several
> runs (weights of the first full-val run are lost). It graduated the moment it matched the anchor; should
> have been in the pipeline with checkpointing immediately. Checkpointing added `@309011a`; graduation below.

## The recipe (what's running: `richaux_20k`, throwaway, `git_rev 309011a`)
- **Net (`RichAuxNet`):** assemble the feature groups → **per-channel `BatchNorm2d`** (equalizes their ~80×
  scale spread: entropy std~0.85, cos std~0.01, LN-feats std~1, deltas std~0.2–1.3 — the std-186 problem's
  OPPOSITE, so BN is the right tool here, unlike on the raw features) → **per-group scalar gate** (after BN;
  a gate before BN would be normalized away) → `Conv1x1` to **dim 32** → residual per-token MLP → the existing
  **`ViewpointQNet` CNN** (`input_norm=False`, since BN already normalizes). Pooled to 32² before the net.
- **Feature groups (2052 ch = 2·1024 + 4):** probe entropy, **entropy Δ**, **cos-dissim to prev**,
  **cos-dissim to the init canvas**, LN canvas features, **LN-feature Δ**.
- **The t0 delta fix [user]:** prev/prev-entropy default to the **INIT canvas (learnable broadcast template)**
  at t0, so the 3 delta groups (1026/2052 ch) carry *deviation-from-template* at the t0→t1 decision instead
  of dead zeros (they were zero → BN → constant; half the input was uninformative at the most important step).
- **Training:** full ADE train (20210, cycled loader, batch 16), K=1 ε-greedy rollout (`prime_on_policy=0.5`),
  `train_horizon=4`, reward = fractional-CE-reduction + online `RunningNorm`, score_res 128, lr 3e-4,
  the QConfig defaults otherwise. **Eval = the REAL protocol** (full val 2000 @ 512², dataset mIoU + CE per
  t0..t4 via a `RichGreedy` policy through `run_episode` — identical bundle to `q.eval`, comparable to the anchor).
